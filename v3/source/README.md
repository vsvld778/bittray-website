# БитТрай — корпоративный сайт

14 статических страниц. Оригинальный логотип сохранён.

Сборка: `python3 build.py`. Готовый сайт — папка `dist`. Можно открыть `dist/index.html` напрямую без сервера.

Редактируемое содержание: services.json, industries.json, approach.json; остальные разделы — build.py. Визуальная система — styles.css, поведение — app.js.

Форма формирует обращение только в браузере; автоматическая отправка отсутствует.

Карта российского рынка: MARKET-REVIEW.md.

Публичная версия: https://vsvld778.github.io/bittray-website/v3/
